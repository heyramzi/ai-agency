# Tella features

Open this before you add a Tella feature to `editor-os`, or when a Tella pass needs something `place` doesn't send. One row per feature of Tella's editor, what the public API reaches, and what we do with it. The cards `place` sends today are in [layouts.md](layouts.md#the-tella-route).

Sources, read 15 Nov 2026: the spec at `https://www.tella.com/docs/openapi.json` (never `docs.tella.tv`, its certificate has expired), `tellahq/skills` on GitHub, and every panel of the live editor clicked through read-only. Every endpoint below is `https://api.tella.com/v1/...` with the `TELLA_API_KEY` bearer. Clip times are ms on the clip's playback clock (cuts applied); `cuts` are raw recording ms; chapters are whole seconds on the final video.

**Read this before you build.** Most timeline adds also go through `POST /videos/{id}/edits`, up to 200 ops checked whole before any lands: `add_|update_|remove_` plus `layout`, `zoom`, `text_overlay`, `media_overlay`, `shape_overlay`, `sound_effect`, `blur`, `highlight`. Use the batch, never a loop of single adds. Anything that needs a file (b-roll, a music bed, our own sounds, a thumbnail) starts with `POST /sources`, a PUT of the bytes to its `uploadUrl`, then `GET /sources/{sourceId}` until it's processed. Tella's MCP (`https://api.tella.com/mcp`) takes the same API key as a bearer and has tools REST doesn't, such as `list_saved_layouts` and `apply_saved_layout`. Calls on one clip go one at a time: two sent together each return the clip as they saw it, so one result can lack the other's cuts though both landed (`tellahq/skills`, tella-auto-cut). A write whose outcome is unclear gets a read first, never a resend: a second add lays a second copy.

`CLI` below is what `editor-os` sends today (`packages/cut/src/backends/tella.ts`, `tella-sections.ts`, `tella-subtitles.ts`, `tella-chapters.ts`, `tella-media.ts`, `tella-music.ts`, `tella-overlays.ts`, `tella-favorites.ts`, `tella-sounds.ts`): pull clips and transcript, PATCH cuts, PATCH `dimensions`, layout sections in one `edits` batch with each card's favorite applied over it, a split per Chapter Card, clip names, the Brand house subtitle preset with names respelled, chapters, the kept music bed, approved motion and b-roll picks as media overlays, the house sound effects, and a 1080p export with subtitles burned in. Nothing else.
