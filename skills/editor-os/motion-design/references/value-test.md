# The test every clip has to pass: what does it add

A clip that draws what the sentence already said is decoration, and his face is more interesting
than any rectangle. Before building anything, answer in one line: **what does the viewer know after
this clip that the sentence did not tell them?** If the answer is "the same thing, but with shapes",
put his face there instead. The four things a graphic can add that a sentence cannot:

- **A quantity made comparable.** "Twenty percent of the system drives eighty percent" is arithmetic
  a listener has to do. A fifth of a grid lit, wired to a bar at four fifths, is done for them.
- **A consequence the read leaves implicit.** He says keep the twenty; he does not say putting the
  eighty down costs a fifth of the output. Draw the cost and the clip has told them something.
- **A structure that has no name yet.** The read names parts in sequence because speech is serial; a
  frame shows them at once.
- **A recognition.** The real logo, screen or word. The moment a viewer sees a tool they have open in
  another tab, the sentence stops being about agencies and starts being about them.

A clip that does none of the four is a cutaway with a budget, and being on-palette, on-clock and
beautifully sprung does not rescue it. **Then the second question:** what does this clip change from
the one before it, and what does it hand to the one after? A clip that can only answer the first is
correct and inert. Both answers go in the header comment, one line each, with the rung it sits on
from the ladder in [storytelling.md](storytelling.md).

**A right clip on the wrong sentence is a wrong clip.** The commonest edit fault is not a weak
graphic, it is a good one landing beside words it does not illustrate: the viewer sees one thing,
hears another, fails to assemble them, and leaves - a cliff in a retention chart that reads exactly
like boredom and gets fixed by cutting faster, which makes it worse. The in-point is therefore part
of a clip's spec, not the editor's discretion: the header comment names the sentence verbatim.
