# Sourcing references, and taking the mechanism rather than the look

Read this at step 1, when the banded competitor sheets have been read and the concept still
has no shape, and again whenever a set comes out looking like the last set.

`niche-evidence.md` answers what separates a winner from a control **inside this niche**. It
cannot answer where a shape nobody in the niche has used comes from, because every frame it
measures is already on YouTube and already in this category. That is what this page is for.

## Ten to fifteen references, from five sources

The count matters as much as the quality: a concept built from two references is a copy of
one of them. Spread them across all five, because four of the five sources are outside the
band sheets and each one fails differently.

| Source | What it is | Where |
| --- | --- | --- |
| Internal outliers | Our own frames that beat the channel average | our own slug in the band script; the repackage table reads the same ranking |
| External outliers | Someone else's frame that beat *their* channel average | The nine competitor slugs, `sheet-winner.jpg` |
| Model channels | Channels making the same **format** on a different **subject** | Not on disk. A build-in-public channel about woodworking is a model channel for a build-in-public channel about software |
| Bookmarks | Frames that stopped the scroll while browsing, saved at the time | A private "thumbnail inspo" YouTube playlist. Save on sight; a frame recalled later is a frame remembered wrong |
| Off-platform | Billboards, film posters, title sequences, album covers, served ads | Frameset for film frames. This is the only source that can hand the niche a shape it has never seen |

**Do not match the topic.** A reference is being collected for its approach, not its
subject, and filtering by topic returns the same frames the band sheets already hold.

## Take the mechanism, not the picture

A reference copied is the control band's own move: the shape arrives without the reason it
worked, so it cannot be adjusted when it does not fit. Three questions per reference, and the
third is the one that carries:

1. What question, if any, does this make me ask?
2. What emotion, if any, does this make me feel?
3. **How does it do that?** Name the device, not the content.

Then transfer the device to this video's claim. The worked example, from the video this page
came out of: a title-sequence frame felt novel with no question attached. The device under
the novelty was **subversion of an expectation**: things that are always flat were rendered
solid. Transferred: YouTube thumbnails are always flat, so draw one that is not. The output
is a composition rule for a frame about a completely different subject, which is what a
mechanism buys and a copied picture does not.

A reference whose third answer is "it just looks good" has not been read yet. Go back to it or
drop it.

## The pass already run on the band sheets, 28 Aug 2026

The three questions were put to four winner sheets. The mechanisms, not the pictures:

**Matt Gray, the withheld object.** `work less`, `just start`, `no one told you`,
`how to get addicted`, `dream killers`. Every line is half a sentence whose object is
missing, and the picture does not supply it either. The click is the missing half. Note
the split of labour: the *location* (villa, mountains, pool) carries the emotion and the
*words* carry the question, never both on one channel. His `$0 -> $10K -> $1M` and
`0 followers -> 846K followers` are the second mechanism, a transformation shown as a
sequence inside one frame.

**Systems Made Better, the viewer supplies the baseline.** `YOUR IPAD. BUT BETTER.`,
`THE APPS THAT MAKE AN IPAD WORTH IT.` The comparison is against the thing the viewer
already owns, so the gap is felt rather than argued. Second mechanism: a red or white
arrow pointing at the exact element, which spends nothing and removes the "what am I
looking at" cost entirely.

**Ali Abdaal, the face is a reaction shot rather than a portrait.** He holds the notebook, the
keyboard, the whiteboard; the hand proves the artifact's scale and that it is real. The
one frame with no artifact works on the opposite move: an extreme close-up of tired eyes
and visible skin, which is vulnerability where a creator photo is normally polished.

**Our own bands, and they correct a rule below.** Both bands name categories, so
"names a category" cannot be the separator it is written up as. What separates them:

- **The winner's noun is a job, the control's noun is a feature.** `MAILBOX TO TASKS`,
  `BUILD A TICKETING SYSTEM`, `CLICKUP CRM MADE EASY` against `EISENHOWER MATRIX`,
  `Tout sur les Docs`, `CLICKUP FEATURES FOR REMOTE TEAMS`.
- **The winner bounds the effort or the scope.** `LEARN IN 30 MINUTES`, `2026 FULL TOUR`,
  `TUTO COMPLET 2025`, `MADE EASY`, `ADVANCED`. No control does.
- **The winner puts its type in the top half and the control does not.** Winners set the
  words across the top; controls hang them bottom-left over a screenshot
  (`CLICKUP FEATURES FOR REMOTE TEAMS`, `ContentFlow`, `La meilleure méthode de travail`).
  This was measured before the TV crop was known about, and it agrees with it.

## Where this lands in the workflow

The mechanism is an input to step 1b, not a replacement for it. The angle still decides the
claim and the payoff; the mechanism decides how that claim is drawn, and it feeds the
template choice at step 5c. A mechanism that no template can express is either a new template
(with its `shipped` list empty until a frame ships) or a mechanism for a different video.
