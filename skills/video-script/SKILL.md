# Video Script

The body is everything after the hook has done its work. It decides whether the
viewer is still there at minute twelve, and whether the one ask at the end lands
on somebody who has already decided.

**This skill does not write the opening.** The first 30 seconds, the hook variants
and the drop-off rating are `video-hooks`, and its measured finding stands: the
hook governs whether people stay, never how many arrive. Read it first, take the
open from it, and come back here for everything after 0:30.

Voice is whatever profile you write in. **Count the first-person pronouns before
it goes to camera: the target is zero.**

**If a generator writes your scripts, the rules have two homes.** This page is the
evidence; the generator holds the runtime copy. Change one and change the other in
the same session, because a rule that only exists in the doctrine never reaches a
generated script, and a rule that only exists in the code has nothing to defend it
when it is questioned. That pair had already drifted once, the generator requiring
prose while the doctrine required bullets, and both files look authoritative alone.

## The three-run control, which is the spine of this skill

Build this measurement for your own niche before trusting the numbers below. What
makes it worth the work is that a creator sometimes re-runs one title construction
several times on the same channel, same offer, same shape, one variable changed per
run, which holds still everything that usually confounds a comparison.

The worked example here is three public runs from one channel, read off YouTube:

| | Nov 2024 | May 2025 | Nov 2025 |
| --- | --- | --- | --- |
| Views | **89,117** | 52,513 | 17,873 |
| Runtime | **19:19** | 29:54 | 28:27 |
| Words | **3,843** | 5,573 | 5,496 |
| Pace | 199 wpm | 186 wpm | 193 wpm |
| Promise in the title | $20,000 | $20,000 | **$100,000** |
| First ask that leaves the video | 98% of runtime | 99% | **11%** |
| Arithmetic on screen | none | one aside | **90 seconds** |
| His own failure, told | **in full** | one line | one line |

The older videos have had longer to accumulate. Adjusted to equal age the $20,000
runs sit around 34,000 to 40,000, so the smaller promise still wins by roughly 2x
rather than 5x. Say the adjustment out loud whenever this table is cited.

Five rules come straight off it.

1. **Nineteen minutes beat twenty-nine.** The evidence is in words, 3,600 to 4,200
   at 190 to 200 wpm, but the script is budgeted in beats, because a word budget is
   a budget on writing and the only way to spend one is to write sentences. See the
   beat budget below. A script past 4,500 words is not more thorough, it is the
   losing run.
2. **The one commercial ask sits in the last twenty seconds.** See the ask rule
   below, which is where this collides with the generic advice and wins.
3. **Tell your own failure in full, in the viewer's words.** The winner is the only
   run that tells the origin story properly: the agency that nearly broke him, the
   margins, the crying on Zoom. The two losers give it one line. Our buyer's life is
   the story, so a script that skips it is a manual. **The failure is the one thing
   about the writer that is allowed on camera, and only because the viewer is living
   it.** The test is whether they can see themselves inside the sentence. A
   credential, a process or a good week cannot pass it, whatever tense it is in, and
   everywhere else in the script every "I" is rewritten as a "you" or cut. The line
   that settles every argument about this: people do not care about you, so every I
   should be a you.
4. **Never compute on screen.** Ninety seconds of arithmetic appears only in the
   losing run. Show the number and its artefact; do not derive it. `video-hooks`
   already holds the proof-frame rule this depends on.
5. **The promise number is one the viewer can picture reaching next quarter.**
   $100,000 addresses the arrived, $20,000 addresses the aspirant, and the
   aspirant outnumbers them. The same effect shows up independently elsewhere: one
   script addressed to "your 20s or 30s" beat "your 30s or 40s" by 11x.

## The ask rule, where two sources of evidence disagree

The generic retention literature says never save the only CTA for the end, because
only 16% of viewers reach the final 10%. The three-run control says the two winners
held every outbound ask to the last 2% and the loser asked at 11% and lost by 3 to
5x. Both are right, because **they are counting different asks.**

- **An in-platform ask** (subscribe, like, comment) costs the viewer nothing and
  never breaks the teach. Place these where the retention data says: one around
  the one-minute mark after the first thing of value has landed, one more later.
  Pair each with something on screen; embedded beats spoken-only by a wide margin.
- **An outbound ask** (buy this, book a call, go to this page) spends the viewer's
  attention and their trust at once. There is exactly one, and it goes in the last
  twenty seconds. A second one does not add a second conversion, it converts the
  video into an ad in the viewer's memory.

If the video exists to sell something, that is an argument for making the teach
complete, not for asking earlier. The winning run teaches for nineteen minutes and
asks once with twenty-one seconds left.

## The script names the overlays, and only its own

Your CTA shelf carries one clip per sellable product plus the on-camera asks (build
it with `youtube-ctas`). Which of them an edit needs is decided by the ask this
script writes, so the script names them by file and the handoff shows those files
alone. Handing the editor the whole shelf hands them somebody else's product, and the
right clip then gets missed among fifteen wrong ones.

One clip for the outbound ask, the one that names what the ask names. A subscribe,
like or comment clip only where a block actually makes that ask on camera. A name that
is not on the shelf is dropped rather than shown, because a tile that leads nowhere is
a download the editor chases.

## What a series buys

One breakout, plus episodes that hold the people already captured. Six episodes ran
17,874, 11,425, 4,144, 5,209, 960, 2,258. Episode five landed below the channel
median. Front-load accordingly: episode one is the reach event, everything after it
is conversion work on an audience you already have.

## One script, one home

**A video has exactly one script**, wherever you keep it, and that is the copy that
gets rewritten, reviewed, teleprompted and recorded from. A course lesson record
(module, surface, status, runtime, takeaways, recording notes) is not a second script.
A lesson that is also a video keeps its spoken beats in one of the two places and the
other links to it. Never both.

## How a script is written down

**A script is bullet points, never prose paragraphs**, and its length is budgeted in
**beats**, not in words, because a word budget can only be spent by lengthening bullets.
One beat is one bullet and runs about seven seconds on camera, so the winning nineteen
minutes is roughly **158 to 185 beats**.

The bullet rules, the 14-word cap, the three lines that are written out in full, the
no-stage-directions rule and the arithmetic behind the beat budget:
[`references/bullets-and-beats.md`](references/bullets-and-beats.md). Read it before
writing a script, because every fault it lists produces a script that clears every other
rule on this page and is still unrecordable.

## Structure

Eight blocks. The beat budget is the constraint that keeps them honest.

| Block | Share | What it does |
| --- | --- | --- |
| Cold open | 0:00-0:30 | Owned by `video-hooks`. Take it from there. |
| The failure | ~8% | Your own, told in full. The buyer's life in your words. |
| The stakes | ~7% | What it costs to keep doing it the current way. One real number, with its artefact. |
| The mechanism | ~15% | The thing that makes it work, named. Lead with this, never with the promise. |
| Build 1..n | ~50% | The teach. One idea per block, each ending in a state the viewer can see on screen. |
| The proof | ~12% | The artefact doing the thing. Two configurations from one input beats one screenshot. |
| The honest limit | ~5% | Who this does not work for, said plainly. It is what makes the rest credible. |
| The ask | last 20s | One outbound ask. Named product, named price, one link. |

**Every build block ends on a visible state change.** A block that ends on a
sentence is a paragraph; a block that ends on the board looking different is a
beat. This is what carries the open loop the completion data rewards.

## Camera language on the outside, mechanics on the inside

This binds every script that sells. On camera the words are the ones your buyer
already uses: "batches, sprints of one week", "a clear view on your team's capacity
without hiring a project manager", "billable time". Your named mechanics, whatever
you call the parts of your own system, are explained **inside** the product, never in
the part that sells it.

A build walkthrough sits on both sides of that line, so the split is by block
rather than by video: the teach blocks may name a mechanic once they are showing
it on screen, and the failure, the stakes and the ask stay in camera language
throughout. A viewer who has to learn a vocabulary before they understand the
stakes has already left.

## Register

Short declaratives. The real noun instead of the abstraction. Concrete numbers with
the artefact that proves them, never a rounded estimate standing in for a
measurement. Contrast pairs carry the teaching: what most people do, then what
actually works, then why the difference is mechanical rather than a matter of
taste.

The one rule that overrides register, carried from `video-hooks`: **go as hard as
you like on the mechanism, and every fact underneath it has to be true.** If you
sell on being the founder who shows the real numbers, one invented figure is the only
thing that can cost you that.

## Before it ships

- Beat count inside 158-185, and the runtime that implies stated at the top.
- No bullet past 14 words unless the whole line is a quotation.
- Exactly one outbound ask, inside the final twenty seconds.
- The failure told in full, not summarised.
- Every number traced to something measured, with the artefact named for the edit.
- No arithmetic performed on camera.
- The first-person count is zero outside the failure block and the quoted lines.

## Learned Patterns

Appended when a run surfaces something this skill did not already know. Newest first.

- A word budget is unspendable except by lengthening bullets. Give a generator a beat
  target instead, or it hits the word count by inflating the beats it already has and
  never finds the step it skipped.
- A script can clear every rule on this page and still be unrecordable. The check that
  catches it is reading one bullet aloud: if it is a sentence, it will be recited.
- Doctrine and generator drift silently, because each one looks authoritative on its
  own. Whenever a rule changes, grep the generator for the old rule in the same session.
- The runtime rule ("nineteen minutes beat twenty-nine") is a finding from one channel.
  Re-run the control on yours before quoting it to anyone as a law.
